# KRL Teams — Smart Farming Command Centre

Operational prototype for the Krishi Ratna League Bengal programme.

Product identity: **KRL Teams** / Smart Farming Command Centre.  
This repository is independent of KRL Media Connect.

## Hierarchy
West Bengal → Zone (when known) → Team → District → Assembly Constituency → Agri-entrepreneur → Farm / Garden → Farm 360°

Known zone assignment: Himalayan Giants → Zone 1. Other teams are not zoned yet.

## Numbers
- 5,000 farmers = programme target, not current enrolment
- 360 / 413 / 120 = approved demo-book volumes, not generated operational rows
- 15 official teams only (20-team capacity is internal)
- 294 assembly constituencies

- Amit Shill → Pikas Garden (Dakshin Dinajpur · 39 Balurghat · Dinajpur Defenders by official geography). Not live enrolment. Source YouTube: [Pika's Gardening](https://www.youtube.com/@PikasGardening) (adenium, tulsi, lemon, bougainvillea, lotus). Facebook reel only; no confirmed Instagram.

Source YouTube: [Rupali Garden](https://www.youtube.com/@RupaliGarden) (dragon fruit flowering, pruning, cuttings, fungal care). No confirmed Facebook page or Instagram.
