# KRL Teams — Smart Farming Command Centre

Operational prototype for the Krishi Ratna League Bengal programme.

Product identity: **KRL Teams** / Smart Farming Command Centre.  
This repository is independent of KRL Media Connect.

## Hierarchy
West Bengal → District → Assembly Constituency → Team → Agri-entrepreneur → Farm / Garden → Farm 360°

## Numbers
- 5,000 farmers = programme target, not current enrolment
- 360 / 413 / 120 = approved demo-book volumes, not generated operational rows
- 15 official teams only (20-team capacity is internal)
- 294 assembly constituencies

## Case studies
- Amit Shill → Pikas Garden (Dakshin Dinajpur · 39 Balurghat)
- Krishna Biswas → Rupali Garden (geography not yet recorded)

## Run locally
```
python -m http.server 8788
```

## Architecture
Vanilla HTML / CSS / JS. No framework, no database.
